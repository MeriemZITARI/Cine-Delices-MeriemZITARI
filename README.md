## 🚀 Démarrage du projet

### 🔧 Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev```

➡️ npm run dev lance le serveur backend avec ts-node-dev


### 🖥️ Frontend (React + Vite)

```bash
cd cinedelices_test
npm install
npm run dev```
➡️ npm run dev démarre le serveur Vite pour le frontend React
